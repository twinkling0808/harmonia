아르모니아 배포 순서 (한 번만 하면 됩니다)

■ 1단계. 구글 Apps Script (데이터 창구)
 1) 기존 프로젝트의 Code.gs 를 새 Code.gs(v10) 로 통째로 교체 → 저장
 2) Index(HTML) 파일은 이제 쓰지 않으니 지워도 됩니다
 3) 배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포
    (처음 배포라면: 새 배포 → 유형 '웹 앱' → 실행: 나 / 액세스: 모든 사용자)
    ※ 코드를 바꿀 때마다 반드시 '새 버전'으로 다시 배포해야 반영됩니다.
 4) 나온 '웹 앱 URL' (…/exec 로 끝나는 주소)을 복사

■ 2단계. 앱 화면 올리기 (GitHub Pages)
 1) github.com 에서 새 저장소(Repository) 만들기: 이름 예) harmonia, Public
 2) 이 폴더(app)의 파일 전부를 저장소에 올리기
    (Add file → Upload files → 파일 끌어다 놓기 → Commit)
 3) 올리기 전에 config.js 를 열어 '여기에_배포ID' 부분까지 포함해
    따옴표 안 전체를 1단계의 웹 앱 URL로 바꾸기
 4) 저장소 Settings → Pages → Branch: main / (root) → Save
 5) 1~2분 뒤 https://내아이디.github.io/harmonia/ 주소가 생깁니다. 이게 앱 주소입니다.

■ 3단계. 폰·태블릿에 설치 (단원 모두 한 번씩)
 - 아이폰/아이패드: 사파리로 앱 주소 열기 → 공유 버튼 → '홈 화면에 추가'
   (꼭 홈 화면 아이콘으로 열어야 저장된 악보가 오래 보관됩니다)
 - 안드로이드: 크롬으로 열기 → 앱 첫 화면 위쪽의 '설치하기' 버튼, 또는 메뉴(⋮) → '앱 설치'
 - 카톡 링크로 들어왔다면 위쪽 '기본 브라우저로 열기'를 눌러 크롬/사파리에서 여세요.
 - 크롬에서 "이미 설치됨"이라는데 홈 화면에 없을 때:
   크롬 메뉴 → 설정 → 앱에서 '아르모니아'를 삭제 → 크롬을 완전히 닫았다가 다시 열기
 - 설치 후 와이파이일 때 앱을 열고, 연습할 곡을 '이 기기에 저장'해 두면
   그 곡은 인터넷이 없어도 열립니다. (곡 메뉴의 '이 기기에 저장', 또는 연습곡 묶음의 '묶음 이 기기에 저장')

■ 악보 올리기
 - 새 곡 또는 곡 메뉴 → 관리 → '📷 스캔 촬영': 찍으면 바로 다음 쪽을 찍을 수 있고,
   악보 부분만 자동으로 잘라 반듯하게 펴고 배경을 하얗게 보정해 작게 저장합니다. 다 찍으면 '완료'.
 - 사진·PDF·ZIP 파일도 같은 보정으로 올라갑니다(체크 해제하면 원본대로).

■ 인쇄
 - 곡 메뉴(⋯) 맨 위 '🖨 인쇄용 PDF (A4) 만들기', 연습곡 묶음·무대별 화면의 '전체 PDF'
 - 기기에서 바로 만들어지고, '공유·저장'으로 카톡·프린터 앱에 보내거나 다운로드합니다.

■ 나중에 앱을 고칠 때
 - 파일을 저장소에 다시 올리면 됩니다. 앱을 한 번 닫았다 열면 새 버전으로 바뀝니다.
